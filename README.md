# Sentinel IoT Platform

Personal IoT and cybersecurity project using ESP32, embedded systems and secure device communication.

## Overview

Sentinel is my personal IoT and cybersecurity project.

The objective is to design and build a secure robotic platform using ESP32, Linux, networking and cybersecurity principles.

This repository documents the entire learning journey, from the first LED test to a complete IoT security platform.

## Final Objective

Build a secure IoT platform combining robotics, embedded systems, Linux, networking and cybersecurity principles.
